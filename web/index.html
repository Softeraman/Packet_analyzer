How analysis works: The original C++ Ethernet/IPv4 parser and TLS SNI / HTTP Host extractors process your capture on the server. Packet payloads are not decrypted. Hostname detection requires a complete handshake or HTTP header within a packet; encrypted client hello, fragmented handshakes, IPv6 and PCAPNG are outside this demo's scope. Rule results apply to whole bidirectional flows, including packets before classification. Uploads use temporary files that are deleted after each request; use synthetic captures without personal traffic.
